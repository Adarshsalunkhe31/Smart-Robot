# Smart-Robot
# Smart Car – Arduino Based

An Arduino-based smart robotic car with three operating modes: manual/Bluetooth control, obstacle avoidance, and line following.

## Features

* Bluetooth/Serial controlled movement
* Automatic obstacle avoidance using HC-SR04
* Servo-based obstacle scanning
* Line following using two IR sensors
* L298N motor driver with PWM speed control
  
## Components

* Arduino Uno
* L298N Motor Driver
* DC Motors
* HC-SR04 Ultrasonic Sensor
* Servo Motor
* 2 × IR Sensors
* HC-05 Bluetooth Module
* Battery and Robot Chassis

## Technologies

**Arduino IDE | Embedded C/C++ | Sensors | PWM | Serial Communication | Robotics**
